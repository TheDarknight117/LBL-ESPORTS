# Carpeta de Fuentes Personalizadas Locales (LBL Esports)

Coloca aquí el archivo de tu fuente personalizada que tienes en tu computadora.

### Formatos soportados:
1. **`.woff2`** (Recomendado para máxima velocidad y menor peso en web)
2. **`.woff`**
3. **`.ttf`** (TrueType)
4. **`.otf`** (OpenType)

### Nombre por defecto configurado:
* Puedes nombrarlo como: `mi-fuente.woff2` (o `mi-fuente.ttf`, `mi-fuente.otf`).
* O si tiene otro nombre específico (ej: `bebas-neue.ttf`), avísame y ajustamos el nombre en el CSS.

### ¿Cómo usarla en tu código HTML?
Simplemente usa la clase:
```html
<span class="font-custom">Tu texto con la nueva fuente</span>
```
O con Tailwind:
```html
<h1 class="font-custom text-2xl text-cyan-400">Título con mi fuente</h1>
```
